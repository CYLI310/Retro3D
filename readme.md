# Cyberpunk Arcade Game

A retro-style arcade game with a cyberpunk aesthetic. The game is built using HTML5 Canvas and JavaScript.

## How to Play

- Use the 'A' and 'D' keys or the left and right arrow keys to move the ship.
- Avoid falling off the edges of the road.
- The game gets progressively faster as you play.
- Press 'P' to pause the game.

## Technologies Used

- HTML5
- CSS3
- JavaScript
