# Cyberpunk Wireframe Racer

## Overview

Cyberpunk Wireframe Racer is a fast-paced, retro-arcade racing game with a 90s cyberpunk aesthetic. Navigate an endless, procedurally generated track made of geometric lines, testing your reflexes as the speed progressively increases. The goal is simple: survive as long as you can to achieve the highest score.

This project is built entirely with HTML, CSS, and vanilla JavaScript, using the HTML5 Canvas API for rendering.

## Features

- **Endless Procedural World**: The track is generated on the fly with random turns, ensuring no two runs are ever the same.
- **Increasing Difficulty**: The game features a leveled acceleration system. Every 20 seconds, you'll level up, and the game will get significantly faster.
- **Dynamic HUD**: A heads-up display keeps you informed with real-time stats, including:
    - Score
    - High Score
    - Time
    - Speed
    - Current Level
- **Persistent High Score**: Your highest score is saved locally in your browser, so you can always come back to beat your personal best.
- **Player Representation**: A wireframe ship at the bottom of the screen represents your vehicle, providing a constant point of reference.
- **Pause Functionality**: Need a break? Simply press the 'P' key to pause and resume the action at any time.
- **Visual Feedback**: Receive a "Level Up!" notification on-screen to alert you to the increasing challenge.

## How to Play

- **Controls**:
    - Use the **'A'** or **Left Arrow** key to move left.
    - Use the **'D'** or **Right Arrow** key to move right.
- **Objective**:
    - Stay on the road. The game ends if your ship goes off the edge.
- **Pause**:
    - Press the **'P'** key to pause or unpause the game.
- **Restart**:
    - After a game over, press any key to restart and try again.

## How to Run Locally

This project is a static website and requires no build steps or dependencies.

1.  Clone or download the repository.
2.  Open the `index.html` file in your preferred web browser.

That's it! Enjoy the ride.
